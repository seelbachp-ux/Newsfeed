**kajisho5/ffmpeg-skill** — A local video-editing toolkit for coding agents: 42 typed FFmpeg tools for cutting, captions, aspect-ratio fitting, loudness normalisation, delivery checks and more. It ships as an Agent Skill (Claude Code, Codex, Cursor) and as an MCP server. It needs only `ffmpeg` and `python3`, with no cloud service or API keys. MIT license, about 11.6K stars, with around 3.2K this week.
*Why it's worth a look:* an agent can turn raw simulator recordings into App Store preview videos at the right sizes, without you opening a video editor.
Source: [GitHub](https://github.com/kajisho5/ffmpeg-skill)

**ag-ui-protocol/ag-ui** — The Agent-User Interaction protocol has reached a stable 1.0 with a frozen, JSON-Schema-backed spec. It defines one event stream between an agent backend and any frontend, covering streaming chat, shared state, human-in-the-loop approvals, frontend tools and generative UI. The official SDKs are TypeScript, Python and .NET; a community Swift SDK exists, and integrations include the Claude Agent SDK, LangChain and Google ADK. MIT license, about 21.9K stars, with around 1.3K this week.
*Why it's worth a look:* if you add an AI coach to your app, a stable protocol means a SwiftUI client won't be locked to one agent backend.
Source: [GitHub](https://github.com/ag-ui-protocol/ag-ui)

**FrizzleM/SideInstaller** — An on-device installer for SideStore and LiveContainer, which lets you sideload IPAs with your own Apple account on iOS 27 without a computer. It also adds Shortcuts actions for refreshing sideloaded apps. About 2.1K stars, with around 600 this week. It uses a custom non-commercial license, and the README warns that modified forks can steal Apple ID credentials.
*Why it's worth a look:* it shows where on-device sideloading stands on iOS 27, which matters if you test builds outside TestFlight. Treat it with caution and use only the official repo.
Source: [GitHub](https://github.com/FrizzleM/SideInstaller)
