**mjmirza/app-store-compliance** — A playbook and pre-submission checker covering 117 documented App Store and Google Play rejection patterns, with privacy-manifest checks and a script that reports each risk as BLOCKED, CLEAR or NOT CHECKED. It includes a skill for Claude Code, Codex and Gemini CLI that runs the check before submit commands. It was among today's top gainers on GitHub, with about 380 new stars.
*Why it matters:* Running it before your first App Store submission can catch rejection problems early; its custom license is royalty-free under $20M revenue.
Source: [GitHub](https://github.com/mjmirza/app-store-compliance)

**obra/superpowers** — An agent-skills framework and development method (brainstorm, then plan, then execute, then review) for Claude Code, Codex and other coding agents. It is near the top of overall trending with about 2,000 new stars today, and the v7.0.x releases rebuilt the brainstorming step and made plans leaner.
*Why it matters:* It gives you a disciplined spec-to-plan-to-build loop when a coding agent writes most of a SwiftUI rewrite.
Source: [GitHub](https://github.com/obra/superpowers)

**suversal/WrapPin** — A community fork of Roam Control that sets the location an iPhone reports through iOS's developer location-simulation channel. It can also simulate walking or driving movement along a route, with on-device pairing on iOS 27 and installation through SideStore. It is the fastest-rising Swift repo today.
*Why it matters:* You can test GPS-tracked workouts, distance and pace logic on a real device without leaving your desk, though its README lists a noncommercial license and setup is fiddly.
Source: [GitHub](https://github.com/suversal/WrapPin)

**google-labs-code/stitch-skills** — A set of Agent Skills for Google's Stitch MCP server, compatible with Claude Code, Cursor, Codex and Gemini CLI. Its skills generate designs, extract a DESIGN.md design system, and turn code into designs; it is Apache-2.0 and trending today.
*Why it matters:* Using it to capture a design system for an existing app before rebuilding it natively is a quick way to keep the visual language consistent, though its build targets are web and React Native, not SwiftUI.
Source: [GitHub](https://github.com/google-labs-code/stitch-skills)

**sw33tLie/macshot** — A native macOS screenshot and screen-recording tool with annotation, redaction and OCR, trending in Swift today.
*Why it matters:* It is a free way to capture and annotate simulator screenshots and recordings for App Store listings and bug reports.
Source: [GitHub](https://github.com/sw33tLie/macshot)
